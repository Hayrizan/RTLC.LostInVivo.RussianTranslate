# Метрики надписей воспоминаний — 0.1.3

## Изменение

Прежняя версия ограничивала надпись только экраном и добавляла переносы каждые 18 символов. Глифы оригинального HoneyRoom и русского MrPixel имеют разные метрики. Поэтому короткие русские фразы получались шире и выше, а добавленные переносы многократно увеличивали высоту длинных фраз.

Теперь для каждого DIALOG/DIALOG2 сохраняется исходный английский образец в исходном шрифте до замены. Измеряются видимые границы глифов с учётом fontSize, fontStyle, lineSpacing и исходных переносов. Русский текст подгоняется в английскую область единым коэффициентом characterSize. Дополнительные переносы удалены. Выбранная кириллическая гарнитура, материал, растр глифов, fontSize и анимация transform/цвета сохранены.

При разной длине перевода отношение ширины к высоте всей фразы различается. Поэтому две стороны прямоугольника не растягиваются независимо: сохраняется форма букв, одна сторона может быть короче оригинала. Дополнительное ограничение экраном продолжает работать при экстремальной анимации.

FontManager сохраняет ссылку на исходный Unity-шрифт перед подменой, в том числе если обработка сцены произошла раньше Start триггера. Регистрация метрик поддерживает неактивные объекты.
