# Галерея Showroom — 0.1.7

Исправлены пересечения подписей и видимость текста через непрозрачные стены и модели.

Проверка в Unity уточнила ошибочное предположение версии 0.1.6: фактический исходный шрифт 46 подписей — MotorolaScreentype, размер по умолчанию 16. Предыдущая поправка размера только для November пропускала эти компоненты. Теперь любой исходный шрифт Showroom сохраняет свой размер, если TextMesh.fontSize не задан.

Одного ограничения английскими метриками недостаточно для тесно стоящих экспонатов. Подписи с одинаковой ориентацией, на одной глубине и в одном ряду получают доступную ширину по расстоянию между их центрами. Каждая надпись занимает не более 88% ближайшего интервала. Меняется только единый characterSize, пропорции глифов сохраняются. Обрабатываются и строки без изменения перевода.

Материал каждой подписи использует штатный GUI/3D Text Shader с проверкой глубины. Он использует альфа-канал шрифтового атласа и цвет вершин TextMesh. Обычные Sprite/Unlit шейдеры для этого атласа не подходят: при нативной проверке они давали чёрные/невидимые глифы. Ссылки на атлас обновляются при его перестройке; материалы освобождаются вместе с компонентами.

Проверка выполнена на Unity 2018.2.21f1 / Direct3D11 в изолированной копии с companyName=RTLC Verification, productName=Lost in Vivo Probe. Все исходные игровые корни сцены деактивированы до Start; проверочные TextMesh скопированы с исходными положениями, поворотами, масштабами и параметрами. Основное прохождение не загружалось, ввод клавиатуры/мыши не отправлялся.

- 46/46 подписей получили исходный размер 16 и новый материал.
- 51 пара в одном ряду проверена по фактическим Renderer.bounds: пересечений нет.
- 46/46 подписей дают видимые пиксели на отдельном рендере.
- 46/46 проверок непрозрачной стены: изображение с текстом за стеной побайтно совпадает с изображением без текста.
- RESULT=PASS. Полный протокол: SHOWROOM_0.1.7_verification.txt.
- Сборка: 0 ошибок, 11 прежних предупреждений.
- DLL/PDB 0.1.7 установлены с проверкой SHA-256. Текстуры, шрифты и каталог не менялись.
