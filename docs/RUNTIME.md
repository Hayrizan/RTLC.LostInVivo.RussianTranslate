# Устройство плагина

Текущий формат с версии 0.2.0: рядом находятся только `RTLC.LostInVivo.RussianTranslate.dll` и `rtlc.bundle`. Подробности сборки и проверки — [ASSET_BUNDLE_0.2.0.md](ASSET_BUNDLE_0.2.0.md).

Проверенная цель сборки: Unity 2018.2.21f1, Windows x64, Mono/.NET 3.5, BepInEx 5.4.23.5. Исходные игровые сборки используются только как ссылки с `Private=false`; в выходной каталог не копируются.

## Вывод текста и сохранность логики

`UnityEngine.UI.Text.text` и `TMPro.TMP_Text.text` остаются исходными. Harmony перехватывает аргументы в `TextGenerator.PopulateWithError` и `TMP_Text.StringToCharArray`, то есть перед созданием геометрии и вычислением размеров. Это сохраняет сравнения английских строк в `NEW_MENU_SCR` и `Menu_Item_scr`, а также имена предметов, ключи PlayerPrefs и ресурсов.

Исключение для посимвольной печати: перед `typewrite_scr.Start` переводится только массив отображаемых фраз `goatText`. Иначе игра передаёт рендереру незавершённые английские префиксы, отсутствующие в словаре. После перевода игра сама печатает русскую строку в исходном темпе.

`TextMesh` и устаревший `GUIText` используют нативный рендерер Unity: текст этих компонентов обновляется после загрузки сцены и с интервалом 0,5 секунды. Исходная и выведенная строки сохраняются для диагностики. Записки копируют содержимое TextMesh в uGUI; повторный перевод уже русской строки не изменяет её. Новые компоненты, созданные во время игры, подхватываются тем же ограниченным сканированием. Полного обхода каждый кадр нет.

## Словари

Внутри `rtlc.bundle` находится `translations/ru.json`:

```json
{"entries":[{"source":"NEW GAME","translation":"НОВАЯ ИГРА"}]}
```

Поддерживаются точное соответствие, нормализация пробелов и `<br>`, затем построчный перевод. Варианты с одинаковыми словами и разными пробелами/переносами разрешены (точные исходники сохраняют свой перевод); разные слова для одинаковой нормализованной строки считаются ошибкой загрузки. Из того же бандла читается `translations/rules.json`:

```json
{"rules":[{"pattern":"^NEW GAME \\+(\\d+)(.*)$","replacement":"НОВАЯ ИГРА +$1$2"}]}
```

Правила выполняются последовательно; для найденного правила возвращается его результат. Онлайн-перевода и сетевых обращений нет. Кэш результатов ограничен 12000 строками, чтобы таймеры не увеличивали потребление памяти бесконечно.

## Шрифты

Обычные Unity Font загружаются прямо из бандла как динамические шрифты со встроенными TTF. Используются Ithaca, Fixedsys Excelsior, MrPixel RTLC, GothicRus Condenced и Liberation Serif; установка шрифтов в Windows и изменение реестра не требуются. Резерв — встроенный Ithaca. Соответствия исходным шрифтам по-прежнему задаются в исходном `assets/fonts/mappings.json`; поле `osFamily` теперь означает ключ встроенной гарнитуры.

Для старого TMP прежние SDF-атласы Ithaca/Noto Sans создаются из JSON и PNG внутри бандла. Их метрики и исходные байты сохранены. Редактируемые шрифты, атласы и лицензия остаются в `assets/fonts/` проекта, затем пакет пересобирается.

## Текстуры

PNG и `Textures/manifest.json` находятся внутри бандла. Редактируемые исходники — `assets/textures/` проекта. Формат манифеста:

```json
{"entries":[{"name":"splash2_spr","width":320,"height":180,"file":"splash2_spr.png","overlay":true,"pointFilter":true,"clamp":false}]}
```

Совпадение проверяется по исходному имени и размерам текстуры. При `overlay=false` PNG служит полной заменой; при `overlay=true` PNG — прозрачный типографический слой. Оригинал считывается через временную GPU RenderTexture, слой компонуется один раз и результат кэшируется. Размер PNG обязан совпадать с указанным. Файлы игры не переписываются.

Текущий установленный пакет содержит 68 пользовательских полноразмерных замен, включая карты нормалей `Vend_N` и `Vend2_N` с переводом `PUSH` → `ЖМИ`. В версии 0.1.1 подмена интерфейсных текстур и материалов предметов выполняется при назначении/создании; периодический обход служит дополнительной проверкой. Предыдущие 65 PNG сохранены побайтно. Подробности правки: [надпись на вендинговом автомате](VENDING_PUSH_AUDIT.md).

Поддерживаются `RawImage`, `Image`, `SpriteRenderer` и все texture slots материала `Renderer` через `Material.GetTexturePropertyNames()`. Для материалов создаются копии, сохраняя shader/свойства оригинала. Для карт нормалей поддерживаются `linear:true` и отдельный PNG `mask`: его красный канал задаёт вес интерполяции всех RGBA-каналов слоя, позволяя сохранить alpha в формате DXT5nm. Запакованные повёрнутые SpriteAtlas потребуют отдельной реализации, если обнаружатся в реальных ресурсах.

## Диагностика

Конфигурация находится в `BepInEx/config/com.rtlc.lostinvivo.russian-translation.cfg`. Файлы диагностики и команд находятся в `BepInEx/cache/RTLC.LostInVivo.RussianTranslate/diagnostics/`, вне папки плагина:

- `[Textures] Enabled=true` — применять русские текстурные замены; `false` оставляет оригинальные изображения, сохраняя русский текст и шрифты. После изменения перезапустите игру.

- `LogMissingTranslations=true` — непереведённые строки в `missing.jsonl`;
- `SnapshotOnSceneLoad=false` — автоматический снимок отключён;
- для ручного снимка создайте `command.txt` со строкой `snapshot`; результат — `snapshot.txt`;
- `scene-state.txt` — последний диагностический снимок состояния сцены.

Диагностика не меняет сохранения и не добавляет файлы рядом с DLL и бандлом.

## Проверки при разработке

`tools/build.ps1` собрал DLL без ошибок. Компилятор предупреждает о двух обращениях к `GUIText`, намеренно поддержанному из-за старого игрового runtime; CS0649 у DTO объясняется заполнением полей из JSON через Unity JsonUtility, а не C#-присваиваниями. Предупреждения не подавляются. Проверена непустая маска всех 66 русских букв в созданном SDF-атласе. Фактический вывод, размер строк, работа меню и смена сцен проверяются в запущенной игре отдельно.
