# Аудит шрифтов Lost in Vivo

Проверена установленная Steam-версия на Unity 2018.2.21f1 / Mono x64 (21.10.2026). Проверялись таблицы `cmap`, непустые контуры русских букв и запечённые таблицы символов TextMeshPro. Проверка только через `Font.HasCharacter` здесь недостаточна.

## Шрифты, для которых нужны русские аналоги

| Имя ресурса Unity | Название семейства | Вид | Поддержка русского | Выбранная замена |
|---|---|---|---|---|
| `MotorolaScreentype` | Motorola ScreenType | Узкий пиксельный гротеск | Пустые контуры русских букв | `Ithaca` (`Ithaca.ttf`) |
| `novem___` | November | Пиксельный шрифт с засечками | Отсутствует | `Fixedsys Excelsior` (`FSEX302.ttf`) |
| `HoneyRoom` | Honey Room | Тонкий округлый пиксельный шрифт | Отсутствует | `MrPixel` (`MrPixel.ttf`) |
| `Ysgarth` | Ysgarth | Готический, с рублеными углами | Отсутствует | `GothicRus Condenced` (`gothicrus-condenced3.ttf`) |
| `Tsulehisanvhi` | Tsulehisanvhi | Моноширинный печатный шрифт с засечками | Отсутствует | `Liberation Serif` (`LiberationSerif-Regular.ttf`) |

Все 5 замен проверены: содержат символы кириллицы. Начиная с версии 0.2.0 шрифты динамически загружаются из AssetBundle плагина; установка шрифтов в Windows и изменение реестра не выполняются.

## TextMeshPro

В игре старый TextMeshPro с уже запечёнными атласами; простая установка системного `.ttf` не добавляет в них символы.

| Ресурс | Символов в атласе | Русские буквы | Выбранная замена |
|---|---:|---|---|
| `LiberationSans SDF` | 250 | Все 66 отсутствуют | `NotoSans-Regular` (SDF-атлас 48pt, 2048x2048) |
| `MotorolaScreentype SDF` | 98 | Все 66 отсутствуют | `Ithaca` (SDF-атлас 48pt, 2048x2048, 439 глифов) |

Для первого достаточно обычного кириллического гротеска; для второго можно использовать тот же аналог, что выбран для `MotorolaScreentype`. Плагину потребуется создать совместимый атлас или перенаправить вывод на кириллический шрифт.

Также имеется встроенная ссылка Unity `Arial` (`Resources/unity default resources`, Path ID `10102`) без встроенных данных и без запечённых символов. По этому ресурсу нельзя делать вывод о покрытии кириллицы: его разрешение системой проверяется во время запуска.

## Воспроизведение аудита

```powershell
python tools/audit_assets.py "<путь к игре>\LIV_Data" "$env:USERPROFILE\.cache\lost-in-vivo-ru\assets"
```

Исходные шрифты и текстуры извлекаются только в указанную папку вне репозитория. Превью собственных тестовых фраз: `%USERPROFILE%\.cache\lost-in-vivo-ru\assets\fonts_preview.png`. Пустые строки под Motorola ScreenType и Tsulehisanvhi в этом превью — результат отсутствующих/пустых русских глифов, а не ошибка генератора изображения.

Версия 0.1.4 использует производный MrPixel RTLC для HoneyRoom: [исправление базовой линии Ы/Я](FONT_BASELINE_0.1.4.md). Исходный файл MrPixel.ttf сохранён.
