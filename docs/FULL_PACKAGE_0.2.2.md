# Финальная версия 0.2.2

Архив для установки: `dist/RTLC.LostInVivo.RussianTranslate-0.2.2-Full-BepInEx-x64.zip`.

В дополнение к версии 0.2.1 добавлен параметр конфигурации `[Textures] Enabled`. Значение `true` включает русские текстурные замены (по умолчанию); `false` оставляет игровые текстуры оригинальными, сохраняя перевод текста. Параметр включён в готовый BepInEx config в архиве. После смены значения нужно перезапустить игру.

Архив содержит BepInEx 5.4.23.5 x64, Doorstop 4.5.0 и плагин. В папке плагина только DLL и `rtlc.bundle`. Все записи ZIP и контрольные суммы проверены `tools/build_full_package.py`. Сборка DLL завершилась без ошибок; игровой процесс для финального runtime-прогона не запускался.
