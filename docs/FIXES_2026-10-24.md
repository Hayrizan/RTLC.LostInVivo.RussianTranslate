# Исправления 0.1.1 — 24 октября 2026

Установлено в `<GAME_DIR>\BepInEx\plugins\RTLC.LostInVivo.RussianTranslate`.

## Текстуры инвентаря

Причина задержки — периодический обход раз в 0.5 секунды после создания предмета. Добавлены синхронные подмены `RawImage.texture`, `Image.sprite` и обработка материалов сразу после `Inv_Item.Spawn`. При загрузке сцены текстуры обрабатываются до первого кадра. Отрицательный кэш материалов убран: материал без текстуры на первом обходе может получить её позже.

В настоящем Unity 2018.2.21f1 проверены setter RawImage и создание оригинального ресурса manual_INV через Inv_Item.Open. Его материал manual_mat использует свойство __Main; оно содержит RTLC manual_D уже при возврате Spawn, без ожидания кадра.

## Обозначения управления

В словаре руководства восстановлены исходные названия клавиш: Left Control, Left Shift, Space, mouse wheel, Left Mouse, Right Mouse, Escape. Подсказки действий остаются русскими. Аналогично сохранены Left Stick и Dpad в варианте для геймпада. Словарь пересобран: 617 записей, 0 конфликтов.

## Записки на земле

Предыдущая схема читала Renderer.bounds после временного изменения transform; Unity могла вернуть старые границы. Новый WorldNoteLayout строит геометрию глифов из реальных CharacterInfo, затем подгоняет её под Mesh.bounds бумаги с полями 12%. Динамический атлас шрифта обновляется через Font.textureRebuilt. Исходный TextMesh сохраняет полный текст для окна чтения.

Материал использует Sprites/Default с обычной проверкой глубины, вместо GUI/Text Shader, который показывает текст сквозь стены.

Проверено в движке:

- записки School_Note_1 из SUBWAY_01C и SUBWAY_02: вершины глифов внутри бумаги;
- тестовый лист с поворотом и неравномерным масштабом: все вершины внутри полей;
- рендер текста изменяет 10486 пикселей видимого листа;
- при перекрытии стеной разница между кадрами с включённым и выключенным текстом — 0 пикселей;
- полный текст для чтения не меняется.

## Чёрный экран в комнате зеркал

Причина воспроизведена без русификатора. В SUBWAY_03B после события пересекаются триггеры выхода в SUBWAY_03C и расплавленного тела. Дублированный Examine_repeat_scr на теле перезаписывает Sys_scr.stage=2 на stage=1, оставляя активный чёрный overlay и не выполняя загрузку.

Контрольный запуск без DLL русификатора, SUBWAY_3B=1, позиция игрока (1.2,0.8,92.0): через 7 секунд сцена всё ещё SUBWAY_03B, level=SUBWAY_03C, stage=1, real_stage=0, overlay=True, alpha=1.

Защита 0.1.1 только для SUBWAY_03B блокирует OnTriggerStay и FixedUpdate у Examine_repeat_scr во время стадий перехода 2/4. При той же проверке загружается SUBWAY_03C, overlay=False, real_stage=0. Боковой выход в SUBWAY_03F также работает. Исходные имена сцен, точки появления и файлы игры не изменены.

## Midnight

Латинские имена игроков, время и номера мест сохраняют оригинальные TMP-шрифт и материал. Кириллический атлас назначается только для текста с кириллицей; при смене содержимого исходный шрифт восстанавливается. Кэш разделён по экземплярам шрифта и материала, учитывает клоны префабов.

В движке проверены исходный MotorolaScreentype SDF, сохранение исходного материала для PastelRose/чисел, назначение кириллического шрифта и возврат к исходному.
