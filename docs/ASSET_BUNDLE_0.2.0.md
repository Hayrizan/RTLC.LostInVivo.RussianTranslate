# Комплект из DLL и AssetBundle — 0.2.0

Установленная папка содержит ровно два файла:

```text
BepInEx/plugins/RTLC.LostInVivo.RussianTranslate/
  RTLC.LostInVivo.RussianTranslate.dll
  rtlc.bundle
```

`rtlc.bundle` — настоящий UnityFS AssetBundle, собранный штатным Unity Editor 2018.2.21f1 для Windows x64, с LZ4-сжатием блоков. Отдельные PDB, JSON, PNG, TTF и папки в установленной директории не требуются.

## Содержимое и загрузка

- 617 переводов и 33 динамических правила.
- 68 замен текстур, манифест и необходимые TMP-атласы.
- Семь нативных динамических Font со встроенными исходными TTF.
- Исходные данные двух TMP-атласов, настройки соответствий гарнитур и приложенная лицензия OFL.

PNG и JSON находятся в двоичных TextAsset без обработки изображений импортёром. Runtime читает исходные байты PNG и использует прежние linear/filter/wrap/alpha-настройки TextureManager. Это сохраняет и упакованные каналы карт нормалей. Файлы на диск не распаковываются.

FontManager получает Font непосредственно из бандла, без установки шрифтов в Windows, изменения реестра или выбора системного fallback. Шрифты импортируются с default32 и Smooth. Значение descent в нативном Font приведено к нулю: так устроен прежний Font.CreateDynamicFontFromOSFont в Unity 2018; обычный импортёр записывает отрицательный descent и сдвигает привязку TextMesh. Контуры, TTF и ширины букв не менялись.

BundleResources удерживает бандл до завершения работы плагина. Словарь, правила, текстуры, настройки и атласы загружаются только из него. При отсутствии/повреждении бандла загрузчик выдаёт явную ошибку. Диагностика перенесена в `BepInEx/cache/RTLC.LostInVivo.RussianTranslate/diagnostics/`, поэтому после снимков рядом с DLL остаются те же два файла. Конфигурация BepInEx находится в обычной папке `BepInEx/config/`.

При упаковке обнаружена добавленная пользователем `MN_controls_menu.png`, отсутствовавшая в старом манифесте. Она включена без изменения байтов; число замен увеличилось с 67 до 68. Удалённые текстуры не восстанавливались.

## Сохранность исходников

Прежняя установленная папка целиком перенесена в:

```text
<GAME_DIR>\BepInEx\backups\RTLC.LostInVivo.RussianTranslate_loose_20261024_173358_aecda4
```

Все 95 файлов резервной копии сверены по SHA-256 с состоянием до переноса, включая пользовательские исходники и переводы. Каталог `backups` находится вне `plugins`, поэтому старую DLL BepInEx не загружает.

Рабочие исходники пакета остаются в проекте: `translations/`, `assets/textures/` и `assets/fonts/`. Для будущих правок меняются эти файлы и манифест проекта, затем пересобирается бандл.

## Повторная сборка

```powershell
./tools/build.ps1 -Deploy:$false
```

По умолчанию используется извлечённый в рабочий кэш редактор `E:\.cache\rtlc-unity2018\Editor\Unity.exe`. Другой редактор **2018.2.21f1** передаётся через `-UnityEditor`. Установка редактора в систему не выполнялась. Проект авторинга находится в пользовательском `.cache/lost-in-vivo-ru/bundle-authoring-2018`.

`build_bundle.ps1` создаёт бандл штатным BuildPipeline; `verify_bundle.py` перечитывает готовый UnityFS, сверяет каждый TextAsset и встроенный FontData с исходными SHA-256, проверяет метаданные Font и размеры изображений. `build.ps1` собирает DLL и комплект в `dist/RTLC.LostInVivo.RussianTranslate/`. Без `-Deploy:$false` устанавливается этот комплект с предварительным переносом предыдущей папки в `BepInEx/backups/`.

- Реальная загрузка из папки с ровно двумя файлами: 617 строк, 33 правила, 68 текстур.

- Оба TMP-атласа прошли проверку алфавита.
- Снимки диагностики не создают файлов в директории плагина.
- Галерея: 46 видимых подписей, 51 пара без пересечений, 46 проверок перекрытия стеной — PASS.
- Надписи воспоминаний: 13 основных/альтернативных фраз и проверка исправленной базовой линии Ы/Я — PASS.
- Сборка DLL: 0 ошибок, 11 прежних предупреждений GUIText/JSON DTO.
- Установленные файлы совпали с комплектом по SHA-256; ZIP содержит только два файла внутри папки плагина.
