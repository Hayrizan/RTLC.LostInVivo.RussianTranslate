# MrPixel: базовая линия Ы/Я — версия 0.1.4

В исходном MrPixel прописные Ы (U+042B) и Я (U+042F) расположены на 128 единиц выше общей базовой линии: y=128..1024 против y=0..896 у соседних прописных. Сетка шрифта — 128 единиц, unitsPerEm=1024.

Создан производный `assets/fonts/MrPixel-RTLC.ttf`, семейство **MrPixel RTLC**. Изменены только координаты двух глифов: (x,y) -> (x,y-128). Число контуров, точки, флаги, инструкции и ширина символов сохранены; все остальные глифы, включая раскрытые составные, совпадают с исходником. Исходный MrPixel.ttf сохранён.

Уникальное имя семейства предотвращает использование старого варианта из системного кэша. HoneyRoom/Honey Room сопоставлены с MrPixel RTLC; прочие назначения шрифтов прежние. При изменениях этой производной версии в будущем следует учитывать кэш уже установленного шрифта.

Воспроизводимый генератор: `tools/fix_mrpixel_baseline.py`. Проверена побайтная воспроизводимость готового файла.

## Проверка в Unity

В отдельном Unity 2018.2.21f1 зарегистрировано новое семейство; журнал подтверждает `HoneyRoom -> RTLC MrPixel RTLC`.

При 48 pt:

- Ы: y=5..49 -> -1..43, advance=36;
- Я: y=5..49 -> -1..43, advance=36.

Для всего русского алфавита с Ёё проверены CharacterInfo: только эти две буквы опущены на 6 пикселей. Остальные вертикальные метрики, все горизонтальные метрики и advance прежние. Повторно пройдены 13 фраз и проверка экранных границ при сильной анимации: RESULT=PASS.

Протокол: `<LOCAL_CACHE>\verification_20261024\font-baseline-0.1.4.txt`.

## Установка

Установлены DLL 0.1.4, производный TTF и mappings.json; файлы сверены со сборкой. Все 56 PNG и исходные файлы шрифтов сохранены побайтно. Запущенная пользовательская игра не закрывалась; её загруженная DLL 0.1.3 перенесена в BepInEx/cache, чтобы новая версия применялась при следующем запуске без конфликта блокировки.
